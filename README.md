# DropBeat

DropBeat is a Unity rhythm-physics prototype where a metallic neon ball travels from ring to ring in sync with music. The player hits at the target ring on the beat; the game then solves the required motion so the ball reaches the next ring at the next selected note time.

The project focus is not only classic rhythm timing. It combines beat tracking, procedural level generation, and physics-based movement planning.

## Core Gameplay

- The ball starts on a warmup ring before the music begins.
- The first player hit starts the musical flow.
- Each target ring maps to a note time generated by ALD.
- Press Space, mouse click, or touch when the ball reaches the current target ring.
- Hit grades are Perfect, Great, Late, and Miss.
- Perfect and strong hits trigger ring breakup, grid pulse, and sine-wave background effects.
- The target ring glows from cyan toward pink as the perfect timing moment approaches.
- Missing the target ring and falling below it causes game over.

## ALD: Algorithm Level Designer

ALD turns music into a level asset.

Current ALD responsibilities:

- Analyze the song spectrum and onset energy.
- Estimate BPM and beat phase.
- Detect high-presence beats that are easier for the player to hear.
- Snap notes toward pulse start timing, not only the loudest peak.
- Store generated note times, judge windows, section information, and plane/lane commands.
- Output an `ALDLevelAsset` that the runtime level builder can read.

The ALD editor is available in Unity from:

```text
BeatDrop/ALD/Level Designer
```

Important ALD timing controls:

- `Auto Align Pulse Start`: shifts the beat grid toward the audible start of transients.
- `Snap Notes To Pulse Start`: places generated notes on transient starts while still scoring beat strength from local peaks.
- `Manual Phase Shift (s)`: small manual timing correction. Negative values make notes earlier; positive values make notes later.
- `Pulse Start Search (s)`: search window around a beat candidate.
- `Pulse Start Threshold`: how early in the transient ALD considers the pulse to have started.

Generated ALD assets now store diagnostic timing values:

- Raw beat phase offset.
- Auto pulse-start correction.
- Manual phase shift.
- Final beat phase offset.

## Runtime Motion Terminology

The runtime uses clear motion terminology:

- `delta time`: time remaining until the next target note.
- `delta position`: world-space distance from ball to target ring.
- `V initial`: launch velocity solved when the player hits.
- `V final`: desired arrival velocity at the next ring. The preferred target is near zero for readable timing.
- `gravity`: final acceleration anchor for natural vertical motion.
- `jerk`: changing acceleration over time, used when ballistic motion alone cannot make the arrival feel natural.

The jerk-assisted planner helps the ball arrive close to the ring at the correct note time with a low final velocity.

## Main Runtime Architecture

The main gameplay component is still `GameSynthezerAndController` so scene and prefab references stay compatible. The code is split into focused partial files:

```text
Assets/Scripts/GameSynthezerAndController.cs
```

Core lifecycle and serialized gameplay settings.

```text
Assets/Scripts/GameSynthezerAndController.Motion.cs
```

Ball Rigidbody setup, fixed-step movement, ballistic fallback, jerk flight application, and velocity protection.

```text
Assets/Scripts/GameSynthezerAndController.Timing.cs
```

Input, autoplay, hit judgement, ALD/runtime timing offsets, judge windows, and miss fail logic.

```text
Assets/Scripts/GameSynthezerAndController.Visuals.cs
```

Ring target visuals, hit effects, trail rendering, HUD, level-builder sync, and Inspector validation.

Supporting systems:

- `ALDLevelBuilder`: reads an ALD asset and builds a playable ring chain.
- `BeatFlightPlanner`: ballistic motion solver.
- `BeatJerkFlightPlanner`: jerk-assisted motion solver with near-zero final velocity support.
- `RingSequenceRuntime`: tracks ring ordering and current target progression.
- `BeatDropEffectManager`: owns grid pulse and sine-wave hit effects.
- `SineWaveBurstController`: draws reactive sine-wave line bursts.
- `GridPulseOnlyController`: handles grid pulse and waveform projection.
- `DspBeatSync`: DSP-clock song timing.

## Requirements

- Unity `6000.4.9f1`.
- Universal Render Pipeline `17.4.0`.
- Unity Input System `1.19.0`.
- Git LFS for the large Unity scene file.

The project also includes MCP for Unity in `Packages/manifest.json` for editor automation.

## Setup

1. Install Unity `6000.4.9f1`.
2. Install Git LFS.
3. Clone the repository.
4. Run:

```bash
git lfs install
git lfs pull
```

5. Open the project folder in Unity.
6. Open `Assets/Scenes/BallUpwardMechanicTest.unity`.
7. If needed, run `BeatDrop/FX/Ensure Effect Manager In Scene` to create the scene effect manager.
8. Use `BeatDrop/ALD/Level Designer` to analyze music and generate ALD level assets.

## Controls

- `Space`: hit the target ring.
- Mouse click: hit the target ring.
- Touch: hit the target ring on mobile.
- Autoplayer can be enabled from `GameSynthezerAndController` for timing tests.

## GitHub Notes

This project uses Git LFS because `Assets/Scenes/BallUpwardMechanicTest.unity` is over 100 MB. Pushing without LFS will fail on GitHub.

If GitHub CLI is installed and authenticated, a repo can be created with:

```bash
gh repo create DropBeat --private --source=. --remote=origin --push
```

If GitHub CLI is not available, create an empty repository on GitHub, then run:

```bash
git remote add origin https://github.com/YOUR_USER/DropBeat.git
git branch -M main
git push -u origin main
```
